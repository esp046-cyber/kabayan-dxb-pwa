# Kabayan DXB PWA
No build step. Host over HTTPS (GitHub Pages works).
1. Create a repo on github.com, upload ALL files (keep folder structure).
2. Settings → Pages → Deploy from branch → main / root → Save.
3. Open https://<user>.github.io/<repo>/ on iPhone Safari → Share → Add to Home Screen.
Edit js/routes.js (steps, places, numbers) and js/currency.js (default rate).
